# BOOM
## PROFESSIONAL ANALOG MASTERING CONSOLE
### Developed by Liberty Music Software

**Tagline: THE POWER BEHIND YOUR MASTER.**

---

## 1. PROJECT OVERVIEW

Develop a premium, professional-grade stereo audio mastering plugin named BOOM, created by Liberty Music Software.

BOOM must deliver the experience of a high-end analog mastering studio within a modern digital audio workstation.

The product is inspired by the musical workflow, elegant simplicity and physical character of legendary analog mastering consoles.

The supplied reference image establishes the desired interface layout, hardware realism, large rotary controls, studio environment and overall design quality.

The objective is to create a visually stunning, sonically outstanding and technically reliable mastering solution suitable for music producers, mixing engineers, mastering professionals and independent musicians.

BOOM must combine:

- Authentic analog-inspired mastering sound.
- High-quality digital signal processing.
- Simple and immediate musical controls.
- A complete internal mastering chain.
- Forty professionally designed mastering Styles.
- One hundred functional factory presets.
- Photorealistic vintage hardware graphics.
- Professional loudness and dynamics metering.
- Modern production and streaming requirements.
- Advanced mastering controls accessible through a secondary interface.

The main workflow must remain extremely intuitive.

A user should be able to select a Style, choose a Preset, adjust Input Drive, modify five mastering EQ bands and increase PUSH to obtain a polished master.

The interface must never become unnecessarily complicated.

All processing parameters must control genuine audio algorithms.

Decorative controls without functional DSP are strictly forbidden.

BOOM must be an original Liberty Music Software product, with original graphics, original presets and independently developed audio processing.

Create a large vintage hardware-style INPUT DRIVE control.

Range: -18 dB to +18 dB.

Default: 0 dB.

The control must regulate the level entering the mastering processing chain.

Increasing INPUT DRIVE must influence the input level of the dynamics processors and analog saturation stages.

It must not simply operate as a final volume control.

Implement:

- Stereo-linked operation.
- Optional independent left/right trim.
- Smooth gain transitions.
- Parameter smoothing.
- Click-free automation.
- Accurate numerical gain display.

Moderate levels should remain clean and transparent.

## 5. PUSH — INTELLIGENT MASTERING INTENSITY

PUSH is the signature feature of BOOM.

Create a very large hardware-style rotary control labeled PUSH.

Range: 0–100%.

Default: 0%.

PUSH must be a genuine multi-parameter mastering macro.

It must not behave as a simple volume control.

As PUSH increases, the audio should gradually become more energetic, dense, powerful and polished.

Internally, PUSH must coordinate:

1. Harmonic saturation intensity.
2. Compressor threshold and behavior.
3. Perceived loudness.
4. Transient preservation.
5. Broad tonal enhancement.
6. Low-frequency control.
7. Limiter input drive.
8. Output gain compensation.

### PUSH intensity zones

0–20% — SUBTLE

Very gentle mastering enhancement with minimal coloration.

20–45% — MUSICAL

Additional warmth, punch and density while preserving dynamics.

45–75% — POWERFUL

Stronger mastering character, increased perceived loudness and controlled compression.

75–100% — MAXIMUM IMPACT

Assertive mastering intensity with careful peak management and controlled harmonic saturation.

PUSH must remain predictable across its entire range.

Avoid excessive pumping, harsh distortion or uncontrolled clipping.

All parameter transitions must be smooth and click-free.

At 0%, PUSH must apply no additional macro-driven processing, while the individual mastering modules remain available.

## 6. COMPLETE PROFESSIONAL MASTERING DSP ENGINE

Implement a fully functional stereo mastering chain.

Default signal path:

INPUT TRIM → ANALOG COLOR → MASTER EQ → DE-ESSER → GLUE COMPRESSOR → PEAK LIMITER → OUTPUT TRIM

Each processor must be implemented using genuine DSP.

Processing must operate on the audio signal rather than simply changing control values.

### 6.1 ANALOG COLOR

Create three original analog-inspired character modes.

CLEAN:

Transparent processing with minimal harmonic coloration.

TUBE:

Warm saturation emphasizing smooth harmonic richness.

TAPE:

Soft peak rounding, gentle saturation and subtle frequency-dependent coloration.

Include:

- Drive.
- Mix.
- Output Compensation.
- Bypass.

Use stable nonlinear waveshaping and suitable anti-aliasing techniques.

### 6.2 MASTER EQ

Use the five-band EQ described previously.

The advanced view may expose additional technical parameters while the five main controls remain directly available.

### 6.3 MASTERING DE-ESSER

Implement a professional high-frequency dynamics processor.

Parameters:

Frequency: 3–12 kHz.

Threshold: -40 to 0 dB.

Amount: 0–100%.

Attack: Adjustable fast response.

Release: Adjustable.

Bypass: On/Off.

The de-esser must control excessive high-frequency energy without unnecessarily dulling the entire master.

### 6.4 GLUE COMPRESSOR

Create a mastering-grade stereo-linked compressor.

Parameters:

Threshold: -40 to 0 dB.

Ratio: 1:1 to 4:1.

Attack: 1–100 ms.

Release: 50–1000 ms.

Makeup Gain: -12 to +12 dB.

Parallel Mix: 0–100%.

Stereo Link: On/Off.

Bypass: On/Off.

Implement a stable dynamics detector and smooth gain-reduction envelope.

The compressor must be suitable for subtle mastering rather than only aggressive bus compression.

### 6.5 TRUE-PEAK LIMITER

Implement a professional mastering limiter.

Features:

- Lookahead limiting.
- Transparent peak control.
- Stereo-linked gain reduction.
- Adjustable release.
- Output ceiling.
- Gain reduction metering.
- Optional oversampling.
- True-peak detection using an appropriate oversampled measurement path.

Parameters:

Threshold: -18 to 0 dB.

Output Ceiling: -2.0 to 0 dBTP.

Release: Auto or Manual.

Limiter Mode:

TRANSPARENT.

PUNCH.

LOUD.

Every mode must change actual limiter behavior.

The limiter must prevent unintended output clipping.

True-peak compliance must be verified through measurements rather than assumed.

### 6.6 MASTER OUTPUT

Provide:

- Output Gain: -18 to +6 dB.
- Master Bypass.
- Output Peak Indication.
- Stereo Processing.
- Mono Monitoring.
- Automatic Level Compensation where enabled.

Use safe gain staging throughout the audio chain.

## 17. PROFESSIONAL AUDIO ENGINE REQUIREMENTS

Develop BOOM as a native, real-time audio plugin using a robust audio processing architecture.

Technical requirements:

- Stereo input and output.
- 32-bit floating-point audio processing support.
- Support for 44.1, 48, 88.2, 96, 176.4 and 192 kHz where available.
- Stable operation across common DAW buffer sizes.
- Sample-rate-independent filter behavior.
- Real-time-safe audio callbacks.
- No heap allocations in the audio callback.
- No blocking file I/O in the audio thread.
- No UI operations in the audio thread.
- Smooth parameter interpolation.
- Correct plugin-state serialization.
- Safe preset switching.
- Denormal protection.
- Reliable initialization and shutdown.
- Accurate host transport and automation integration where needed.

Prioritize stability, low latency and controlled CPU consumption.

Document any additional latency introduced by lookahead processing or oversampling.

Report plugin latency correctly to the host.
